# PWA Icons

Place your app icons here:

- `icon-192x192.png` - 192x192 pixels (required)
- `icon-512x512.png` - 512x512 pixels (required)
- `favicon.ico` - 32x32 pixels

## Icon Guidelines

### Design
- Use the MyStream branding (black background with red accent)
- Keep the design simple and recognizable
- Ensure icons work well at small sizes

### Generation
You can use tools like:
- [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [Favicon.io](https://favicon.io/)

### Quick Setup
1. Create a base icon (512x512)
2. Resize to required dimensions
3. Place files in this directory
4. Icons will be automatically referenced by manifest.json
