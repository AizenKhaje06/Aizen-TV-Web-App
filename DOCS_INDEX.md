## 🎨 Documentation Style Guide

### Headings
```markdown
# Main Title
## Section
### Subsection
#### Detail
```

### Code Blocks
```markdown
\`\`\`bash
npm run dev
\`\`\`
```

### Lists
```markdown
- Unordered item
1. Ordered item
- [ ] Checklist item
```

### Emphasis
```markdown
**Bold** for emphasis
*Italic* for slight emphasis
`Code` for inline code
```
