## 🗂️ Cache Strategy Diagram

```
Request Flow:
┌────────────────────────────────────────────────────────────┐
│                      User Request                           │
└──────────────────┬──────────────────────────────────────────┘
                   │
                   ▼
         ┌─────────────────┐
         │  Service Worker │
         │   Intercepts    │
         └─────────┬───────┘
                   │
        ┌──────────┴───────────┐
        │                      │
        ▼                      ▼
┌───────────────┐      ┌───────────────┐
│ Static Assets │      │   API/Data    │
│ (Cache First) │      │(Network First)│
└───────┬───────┘      └───────┬───────┘
        │                      │
        ▼                      ▼
    ┌───────┐              ┌───────┐
    │ Cache │              │Network│
    └───┬───┘              └───┬───┘
        │                      │
        │     On Failure       │
        │◄─────────────────────┘
        │
        ▼
  ┌─────────────┐
  │   Offline   │
  │   Fallback  │
  └─────────────┘
```

### Cache Strategies by Resource Type:

**1. Application Shell (Cache First)**
```
CSS, JS, Fonts, Icons
    ↓
Check Cache
    ↓
Found? → Serve from cache
    ↓
Not found? → Fetch from network → Cache → Serve
```

**2. Images (Stale While Revalidate)**
```
Images (posters, backdrops)
    ↓
Serve from cache (if available)
    ↓
Fetch from network in background
    ↓
Update cache for next time
```

**3. API Data (Network First)**
```
TMDB API requests
    ↓
Try network first
    ↓
Success? → Cache → Serve
    ↓
Fail? → Serve from cache (if available)
    ↓
No cache? → Show offline message
```

**4. Never Cache:**
- Video streams (too large)
- Authentication tokens
- Real-time data
- User-generated content

## 📊 Performance Targets

### Cache Sizes:
```
App Shell:     ~500KB   (HTML, CSS, JS)
Images:        ~5MB     (Posters, backdrops)
API Data:      ~1MB     (TMDB responses)
Total:         ~6.5MB   (Reasonable for PWA)
```

### Load Times:
```
First Load:    < 3s     (Network)
Repeat Visit:  < 1s     (Cached)
Offline:       < 0.5s   (Fully cached)
```
