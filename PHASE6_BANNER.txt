  Cache Strategies:
  Static Assets (Cache First):
  • CSS, JavaScript, Fonts
  • Icons, Manifest
  • Max age: 1 year (fonts), 1 day (others)

  Images (Stale While Revalidate):
  • TMDB posters/backdrops
  • Profile images
  • Max: 64 images, 1 day

  API Data (Network First):
  • TMDB API requests
  • Timeout: 10 seconds
  • Falls back to cache

  Pages (Network First):
  • All app routes
  • Offline fallback: /offline

  User Flow:
  1. Visit MyStream
     ↓
  2. PWA criteria met (HTTPS, manifest, SW)
     ↓

     ↓
  4. Custom banner appears at top
     ↓
  5. User clicks "Install"
     ↓
  6. Browser shows native prompt
     ↓
  7. User confirms
     ↓
  8. App installed on device!
     ↓
  9. Icon appears on home screen/desktop
     ↓
  10. Launch from icon → Standalone mode
